# weather-outfit-builder

Project Goal: This is a Java program to help me decide what to wear each morning based on the weather outside. The goal is to save time (since I tend to be really indecisive) and automate this part of my life.

MVP Scope: The MVP will pull weather data using the OpenMateo API, and then will use a set-up JSON file with all my clothes stored by category and temperature to output 3 options for each clothing category (tops, bottoms, etc.) as a string

Future Plans: Adding in a GUI to display pictures of each item of clothing, Suggesting potential new hairstyles based on the outfit generated, Adding in a feature for event-specific recommendations

Tech Stack: Java, JSON, Jackson Library, OpenMateo API
